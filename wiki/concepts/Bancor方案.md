# Bancor 方案（凯恩斯计划）

> 凯恩斯 1942 年设计的超主权储备货币方案——本可以根治特里芬难题，却败给了美国的"怀特方案"。80 年后回头看，这是国际货币体系**最关键的"差点成功"的替代路径**。

---

## 一、一句话定义

> **Bancor = 凯恩斯设计的、由国际清算联盟（ICU）发行的、与黄金挂钩但不可兑换黄金的超主权记账单位，各国货币以 Bancor 为锚、按固定汇率结算国际贸易，逆差国与顺差国被迫对称调整。**

核心创新不在货币本身，而在**它让"顺差国"也被迫调整**——这条当时只有凯恩斯敢提，今天仍是国际货币体系改革的天花板。

---

## 二、方案机制

### 2.1 发行与价值锚定

```
Bancor（单位记账）
  ├── 不发行实体纸币，只在国际清算联盟（ICU）账本上记账
  ├── 锚定方式：30 个主要国家货币按战前权重组合
  │   （不锚黄金单一，避免重演金本位流动性陷阱）
  ├── 各国货币对 Bancor 设固定汇率（可调整）
  └── ICU 凭贸易结算自动创造/清算 Bancor，无央行人为投放
```

### 2.2 结算流程

| 步骤 | 动作 |
|------|------|
| ① | A 国进口 → 用本国货币从 ICU 换 Bancor，付给 B 国 |
| ② | B 国收 Bancor → 换回本币，存入 ICU 账户 |
| ③ | A 国在 ICU 的 Bancor 账户**负债增加** |
| ④ | B 国在 ICU 的 Bancor 账户**盈余增加** |

**关键**：Bancor 不可兑换黄金，纯靠 ICU 信用。这把特里芬"储备货币发行国必须逆差"的死结**从源头拆掉**——没有主权发行国，没有"某国必须输出货币"的要求。

### 2.3 对称调整机制（Bancor 的灵魂）

这是 Bancor 区别于所有现行方案的精妙设计：

| 国家状态 | Bancor 方案要求 | 现实里谁担责 |
|----------|----------------|-------------|
| **逆差国**（Bancor 负债） | 贬值、紧缩、加储 | 逆差国（被骂、被要求改） |
| **顺差国**（Bancor 盈余超阈值） | **必须升值、扩张内需、降关税**，否则罚息 | ⚪ 现实现行体系下完全不被罚 |

> [!key-insight] 为啥这条最要命
> 现行体系里，**只有逆差国被迫调整**（EM 被骂、被要求紧缩、被迫借美元）。顺差国（德国、中国、日本）可无限积累盈余而无需担责。凯恩斯说这不对——**盈余和赤字是镜子的两面，单边惩罚赤字国是剥削**。所以 Bancor 规定顺差国盈余超过账户额度一半时强制收"稀少货币税"，逼它要么升值要么扩张。

**这条直接动了顺差国的奶酪**。1944 年英国是逆差国，凯恩斯代表英方利益推这条有私心；但客观上这是**唯一能从结构上根治全球失衡**的设计——今天看依然是。

## 三、Bancor 为何能根治特里芬难题

| 特里芬难题的根 | Bancor 怎么拆 |
|----------------|--------------|
| 储备货币发行国必须逆差输出 | Bancor 无主权发行国，ICU 按需清算创造 |
| 主权国家利益 vs 全球利益冲突 | 无主权，国别利益冲突消失 |
| 信心危机来自发行国偿付能力 | 信心来自篮子货币加权 + ICU 信用 |
| 调整负担全压逆差国 | 顺差国对称调整，矛盾不再一边倒 |

完整闭环：

```
现行体系（特里芬在场）
  美国必须逆差 → 全球积累美元 → 信心临界 → 瓦解 → EM 承担成本

Bancor 体系（特里芬消失）
  各国对 Bancor 结算 → 无主权输出压力 → 顺逆差对称调整 → 无单边信心危机 → 全球失衡被压在阈值内
```

## 四、与 SDR 的承继关系

[[SDR]]（1969 年创建）是 Bancor 的**妥协版残品**，关键差异：

| 维度 | Bancor（1942） | SDR（1969-今） |
|------|---------------|----------------|
| 性质 | 真正的清算货币（可记账结算） | 储备资产凭证（不可直接结算） |
| 私人部门 | 计划可用 | 仅限官方 |
| 对称调整 | 顺差国强制 | 无 |
| 发行逻辑 | ICU 自动 | IMF 政治决策（美国可否决） |
| 落地状态 | 被否决 | 半残（占全球储备 <10%） |

**核心判断**：SDR 保留了 Bancor 的"超主权记账单位"形式，**丢掉了 Bancor 的"顺差国对称调整"灵魂**。所以 SDR 从来没真正威胁过美元——它不带调整机制，等于只学了个壳。详见 [[SDR]] 第六节"改革提议"。

## 五、1944 年为何败给怀特方案

完整对决见 [[布雷顿森林对决]]，这里列技术原因：

| 凯恩斯 Bancor | 怀特 White Plan |
|---------------|----------------|
| 超主权货币 | 美元挂钩黄金，其他货币挂钩美元 |
| 顺差国强制调整 | 不约束顺差国 |
| 英国主导设计 | 美国主导设计 |
| 英国黄金已近枯竭 | 美国握全球黄金 70%+ |
| 谈判筹码：英国在衰落 | 谈判筹码：美国在崛起、是债主 |

**一句话**：Bancor 输给怀特，不是因为它在经济学上不对，而是因为 1944 年的美国有黄金、有产能、是英国的债主——**经济学打不过地缘政治**。详见 [[布雷顿森林对决]]。

## 六、Bancor 的现代回响

| 时期 | 事件 |
|------|------|
| 1942 | 凯恩斯提出 Bancor |
| 1944 | 布雷顿森林会议否决 Bancor，采纳怀特方案 |
| 1960 | 特里芬预言美元体系崩溃 |
| 1969 | IMF 创建 SDR——Bancor 的妥协版 |
| 1971 | 特里芬预言应验，美元脱钩黄金 |
| 2008 | 周小川倡"超主权储备货币"，被美欧压制 |
| 2009-2022 | SDR 三次大规模分配（2009/2021/抗疫），但未货币化 |
| 2024 | 金砖国家讨论"BRICS Pay / 多极货币"，仍是 Bancor 思路的变种 |

> [!note] 周小川 2009 倡议
> 2009 年 G20 伦敦峰会前，时任中国央行行长周小川发文呼吁以 SDR 为基础建立超主权储备货币，直指特里芬难题。这是 Bancor 思路 65 年后最接近国际议程的一次。但因美国反对、SDR 无调整机制、人民币当时未国际化，倡议未落地。

---

## 七、Bancor 留给今天的遗产

1. **证明超主权货币在理论上可行**——特里芬难题不是物理学定律，是制度选择
2. **暴露现行体系的隐藏剥削**：顺差国不担责、逆差国担全责——这条 80 年没改
3. **给 SDR 改革指了方向**：缺的不是规模，是**对称调整机制 + 私人市场**
4. **揭示货币体系改革的真实障碍**：技术方案早就有了，卡的是地缘政治（见 [[IMF治理改革悖论]]）
