# 日本95年体制

> 泡沫崩盘后,日本在1995年完成制度定型:放弃出清、选择拖延。
> 超低利率 + 财政兜底 + 护送船团维持银行不破产,这套体制运行了近30年,直到2024年3月才被正式退出。

## 一、一句话定义

**日本95年体制** 指日本在[[泡沫经济]]崩盘后,于1995年前后定型的"拖延式"制度安排:央行把利率压到0.5%的极限低位(零利率前夜),财政以公共资金兜底金融机构坏账,[[大藏省]]的"护送船团方式"继续保护银行不破产,同时日元升值到79-80的历史高位。此后约30年,日本的货币、财政、金融监管三大支柱都在1995年定下的框架内运行——直到[[桥本行政改革]]拆分大藏省、[[日本银行]]独立、[[安倍经济学]]以QQE续命12年、2024年3月退出负利率/YCC才彻底终结。

它不同于"55年体制"(自民党一党独大的**政治**体制):95年体制是**经济政策体制**,描述的是货币+财政+金融监管的"拖延组合"。

## 二、历史坐标:为什么是1995

### 2.1 泡沫崩盘后的政策空间用尽(1990-1995)

- **1985-1991**:[[广场协议]]后日元三年升值约50%;[[金融自由化]]打开热钱大门;央行[[自杀式加息]]在几个月内把基准利率从2.5%提到6%,刺破泡沫
- **崩盘幅度**:股市从约39,000点跌至14,000点([[泡沫经济]]);土地价格从1991年峰值下跌超70%、股市下跌超80%,大量企业净资产转负([[资产负债表衰退]])
- **1991-1998**:政策利率从高位逐步降至0.5%附近([[日元套利交易]]利率表)——名义利率工具基本用尽,这是"95年体制"的货币前提

### 2.2 1995年五件大事

| 事件 | 时间 | 意义 |
|------|------|------|
| 阪神大地震 | 1995.01 | 战后最严重灾害,财政压力剧增 |
| 日元升至79-80历史高位 | 1995-1996 | 出口承压,汇率工具反向失灵 |
| 住专不良债权暴露 | 1995 | 大藏省"护"出6.4万亿日元窟窿,护送船团方式公开破产 |
| 大藏省丑闻连续曝光 | 1995-1996 | 官僚受贿、接待问题,制度合法性瓦解 |
| 利率降至0.5%极限低位 | 1991-1998区间 | 零利率时代前夜,1999年正式零利率 |

## 三、体制四支柱

### 3.1 货币:超低利率→零利率→量化宽松

| 时期 | 政策 | 状态 |
|------|------|------|
| 1991-1998 | 政策利率逐步降至0.5% | 超低利率,95年定型 |
| 1999-2000 | 零利率政策(~0%) | **开启日元套利时代** |
| 2001-2006 | 量化宽松(QE) | 对抗通缩 |
| 2013-2024 | QQE(2%通胀目标) | 安倍经济学续命 |
| 2016-2024.03 | 负利率(-0.1%)+YCC | 套利最盛期 |
| 2024.03起 | 逐步加息 | 体制货币支柱终结 |

(据[[日元套利交易]] §2.1 与[[货币政策正常化]]演变线)

### 3.2 财政:兜底 + 刺激,国债膨胀

- 阪神地震重建 + 住专处理 + 连年刺激,财政压力剧增,国债持续膨胀
- 到正常化时点,日本政府债务/GDP已超260%,财政货币化到极限([[货币政策正常化]])
- 财政端至今仍是体制遗产:2024年度[[厚生劳动省]]预算约35.6万亿日元,占一般会计约1/3,社保给付费133万亿日元占GDP 21%

### 3.3 金融:护送船团不破产

- 1995年住专暴露"护"出6.4万亿窟窿,但体制选择继续护
- 直到1997.11三洋证券倒闭(战后券商首次)、北海道拓殖银行倒闭(战后银行首次)、山一证券自主废业("山一はない"),护送船团神话才破灭([[桥本行政改革]] §2.1)

### 3.4 制度:四权合一不拆

- [[大藏省]]集财政、货币、监管于一身,既是泡沫推手也是危机放大器("自己监管自己")
- 1995年丑闻与住专危机后仍不拆,拖到1998.04日本银行独立、2001.01大藏省拆分为财务省+金融厅

## 四、为什么拖了30年:资产负债表衰退

[[资产负债表衰退]](辜朝明,源于1990年代日本研究)为"拖延"提供了理论辩护:

> 资产价格暴跌后,私人部门优先修复资产负债表而非投资消费;利率失效(零利率也无法刺激投资);财政政策更有效。

95年体制正是把"财政兜底 + 零利率"组合制度化——但它只解决"不崩",不解决"复苏":增长停滞、通缩固化、债务/GDP超260%。这也解释了为什么货币政策正常化如此艰难:政策空间被95年起的30年透支殆尽。

## 五、体制的结局(1997→2001→2013→2024)

| 时间 | 事件 | 意义 |
|------|------|------|
| 1997.11 | 三洋证券/北海道拓殖/山一证券三连爆 | 护送船团神话破灭,体制第一支柱崩塌 |
| 1998.04 | 新《日本银行法》施行 | 央行独立,大藏省主导终结 |
| 2001.01 | 大藏省拆分,1府22省厅→1府12省厅 | 四权合一终结 |
| 2013.04 | QQE启动([[安倍经济学]]) | 给体制续命12年:日经+355%、央行资产+381%、债务+27pp、实际工资-8% |
| 2024.03.19 | 退出负利率/YCC(植田和男) | 体制的货币支柱正式终结 |

[[安倍经济学]]的定论:只打破通缩心理、不动结构僵化根本;劳动人口1995年见顶、老龄化率突破25%,人口拐点是死结——恰与体制定型同年,堪称隐喻。

## 六、启示

1. **拖延有成本**:名义利率工具30年用尽,财政货币化到极限;万亿级日元套利盘(2007年高峰约1-1.5万亿美元)成为全球风险源([[日元套利交易]])
2. **制度重构滞后于危机**:1995年暴露的制度问题,拖到1997年危机才倒逼改革(桥本行政改革),再拖到2001年才落地
3. **对照锚点**:与"出清式"处置对比,以及与中国化债路径的对照,见 [[QE与化债对比]] / [[财政货币化]] / [[化债核心命题]]
