# 陆股通（北向资金）

## 概述

**陆股通**——境外资金通过沪深港通**北向**买卖 A 股的总称，由[[沪港通]]（沪股通）和[[深港通]]（深股通）两部分构成。市场俗称**"北向资金"**，被视为 A 股最重要的边际定价力量之一。

## 关键数据

| 项目 | 说明 |
|------|------|
| 开通时间 | 2014（沪）/ 2016（深） |
| 每日额度 | 520 亿元人民币（北向） |
| 总额度 | 无限制（2018 年取消） |
| 持股偏好 | 消费（茅台、美的）、金融（招行、平安）、新能源（宁德） |
| 外资持仓占比 | 约 5%（A 股流通市值） |

## 机制要点

- **通道**：港交所下单 → 经"北向通"接入沪深交易所
- **结算**：港交所中央结算系统，人民币结算
- **数据披露**：每日公布北向资金净流入/流出（盘中实时）
- **交易规则**：遵循 A 股规则（T+1、涨跌停）

## 市场影响

- **"聪明钱"效应**：北向资金动向被市场解读为外资对中国资产的态度
- **价值发现**：偏好高 ROE、大市值龙头，推动蓝筹估值重估
- **情绪指标**：单日大额净流入/流出常引发 A 股波动（参见 [[A股市场结构]]）

## 历史关键节点

- **2014.11**：沪股通开通，首日净流入超百亿
- **2018**：取消总额度限制；纳入 MSCI，外资被动配置增加
- **2019-2020**：北向持续净流入，A 股"机构化"加速
- **2021-2022**：北向波动加大，成为市场情绪风向标
