# 凯恩斯主义（Keynesian Economics）

> 凯恩斯主义是 20 世纪影响力最大的宏观经济思想流派——它把"有效需求不足"确立为资本主义波动的核心命题，并用积极的财政与货币政策作为对冲工具。[[Bancor方案]]、布雷顿森林体系 IMF 的设计，都有凯恩斯的直接印记。

---

## 一、一句话定义

> **凯恩斯主义 = 在自由市场无法保证充分就业的前提下，由政府通过财政支出与货币宽松主动管理总需求，以稳定经济周期的宏观经济学说。**

核心命题：**有效需求不足**导致非自愿失业，市场不会自动出清到充分就业——政府必须逆周期干预。

---

## 二、历史脉络

| 时期 | 事件 |
|------|------|
| **1936** | 凯恩斯出版《通论》，创立宏观经济学 |
| **1944** | 凯恩斯代表英国参加布雷顿森林会议，提 [[Bancor方案]]（详见 [[布雷顿森林对决]]） |
| **1945-1960s** | "凯恩斯革命"席卷西方，新古典综合派（萨缪尔森）成主流 |
| **1970s** | 滞胀出现，货币主义/理性预期学派反击 |
| **1980s** | 里根/撒切尔新自由主义，凯恩斯主义退潮 |
| **2008** | 全球金融危机后，"新凯恩斯主义"回归——QE、财政刺激 |
| **2020** | COVID 大规模财政转移支付 + 无限 QE，凯恩斯工具全面应用 |
| **2020s** | 化债、MMT 争论——凯恩斯主义演化进入新阶段 |

## 三、核心理论

### 3.1 有效需求不足

```
古典：供给创造需求（萨伊定律）→ 充分就业自动实现
凯恩斯：供给不会自动创造需求 → 有效需求不足 → 非自愿失业
```

**有效需求** = 消费 + 投资 + 政府支出 + 净出口中，企业预期有利可图的总需求。低于充分就业产出时，市场不会自动补上，需要政府发力。

### 3.2 三大心理规律

凯恩斯用三条规律解释有效需求为何不足：

| 规律 | 机制 |
|------|------|
| **边际消费倾向递减** | 收入↑但消费增速慢于收入 → 储蓄缺口扩大 → 需求不足 |
| **资本边际效率递减** | 投资越多预期回报越低 → 投资不足 |
| **流动性偏好** | 利率不能无限下降（流动性陷阱）→ 货币政策失效 |

### 3.3 政策主张

- **财政政策为主动力**：政府支出补需求缺口，乘数放大（见 [[财政政策乘数]]）
- **货币政策为辅**：降利率刺激投资，但遇流动性陷阱失效
- **逆周期操作**：衰退时扩张，繁荣时紧缩，平滑周期

## 四、核心模型与工具

### 4.1 IS-LM 模型

详见 [[IS-LM模型]]：

- **IS 曲线**：商品市场均衡（投资=储蓄），反映财政政策
- **LM 曲线**：货币市场均衡（货币需求=供给），反映货币政策
- **均衡点**：决定利率与产出
- 凯恩斯主义的政策分析框架——财政使 IS 右移、货币使 LM 右移

### 4.2 财政乘数

详见 [[财政政策乘数]]：

```
ΔY = k × ΔG    （k 为乘数，k = 1/(1-c) , c 为边际消费倾向）
```

政府每花 1 元，GDP 多增 k 元。凯恩斯派主张衰退时积极使用，但乘数大小有争议（危机时可能 >1，开放经济可能 <1）。

### 4.3 流动性陷阱

详见 [[流动性陷阱]]：

- 利率降到接近零，货币需求弹性趋于无穷
- 央行再放水也不降利率、不刺激投资
- 1930s 大萧条、2008 后日本/欧元区出现过
- **此时只能靠财政政策**——这是凯恩斯主义最强论据

### 4.4 量化宽松（QE）

详见 [[量化宽松]]、[[扩表与缩表]]：

- 央行购买长期资产压低长期利率，绕开短期利率零下界
- 2008 美联储首创，日本/欧元区跟随
- 是凯恩斯主义在"流动性陷阱 + 不能再用财政"时的货币政策变种

## 五、分支与演化

| 分支 | 核心主张 | 代表 |
|------|---------|------|
| **正统凯恩斯主义** | IS-LM + 财政主动性 | 萨缪尔森、托宾 |
| **新古典综合** | 凯恩斯短期 + 古典长期 | 萨缪尔森 |
| **后凯恩斯主义** | 不确定性、金融不稳、Minsky 时刻 | 明斯基、罗宾逊 |
| **新凯恩斯主义** | 价格粘性 + 微观基础 + DSGE | 曼昆、伯南克、斯蒂格利茨 |
| **现代货币理论（MMT）** | 主权货币国财政无约束、税收创造需求 | 沃伦·莫斯勒、凯尔顿 |
| **新新凯恩斯** | 财政乘数小、垂直 IS 曲线 | 2008 后部分研究 |

详见 [[现代货币理论 (MMT)]]：MMT 是凯恩斯主义的激进延伸，主张主权货币发行国财政不受税收约束，财政赤字=私人部门盈余。

## 六、与其他学派对比

| 学派 | 对萧条成因 | 政策主张 |
|------|-----------|---------|
| **凯恩斯主义** | 有效需求不足 | 财政+货币逆周期 |
| **货币主义（弗里德曼）** | 央行放水不足致大萧条 | 规则化货币增长，反对相机抉择 |
| **新古典/理性预期** | 市场自动出清，干预无效 | 反对干预 |
| **奥地利学派** | 人为压低利率致错误投资 | 反对宽松，该让泡沫出清 |
| **供给学派** | 高税收抑制供给 | 减税、放松管制 |

**核心分歧**：是否相信市场能自动出清到充分就业。凯恩斯说不，其他学派说能。

## 七、凯恩斯主义与货币体系

### 7.1 Bancor 方案与布雷顿森林

凯恩斯不仅在理论上主张政府干预，还在国际货币体系设计中贯彻他的思想：

- [[Bancor方案]]：超主权货币 + 顺差国对称调整机制，本质是**全球层面的凯恩斯主义**——不让顺差国囤积、不让逆差国独自承担调整
- [[布雷顿森林对决]]：凯恩斯的国际清算联盟方案败给美国的美元方案，但布雷顿体系本身保留了 IMF 这个"全球最后贷款人"角色
- 详见 [[IMF治理改革悖论]]——为何凯恩斯国际改革思路至今难落地

### 7.2 国际协调的凯恩斯逻辑

- 各国逆周期政策协调 = 全球层面的 IS-LM 管理
- IMF 的"条件性"贷款本质是要求逆差国接受凯恩斯式紧缩，但**不约束顺差国**——这正是 Bancor 试图补上的对称调整机制
- 2009 周小川倡议超主权储备货币 = 21 世纪的凯恩斯主义回响

## 八、2008 与 2020：凯恩斯主义的两次大回归

### 8.1 2008 全球金融危机

- 美联储启动 QE（2008-2014），资产负债表从 0.9 万亿 → 4.5 万亿美元
- 奥巴马 7870 亿美元财政刺激
- **特征**：货币宽松为主，财政迟疑 → 流动性陷阱下 QE 撑场
- 详见 [[扩表与缩表]]、[[量化宽松]]

### 8.2 2020 COVID 危机

- 美联储无限 QE + 0 利率，资产负债表冲至 8.9 万亿美元
- 美国 CARES Act 等财政转移支付超 5 万亿美元（直接发钱）
- **特征**：财政+货币双管齐下，凯恩斯工具全面应用
- 详见 [[2020美国财政刺激]]、[[TGA机制]]

### 8.3 后果争论

- 拯救了经济，但留下高通胀（2022 CPI 9.1%）
- **凯恩斯主义在"退出"上历来薄弱**：刺激容易，回收极难（见 [[美联储独立性]]、[[货币政策正常化]]）
- 化债问题（中国 [[2023年化债]]）某种意义上也是"刺激留下的债怎么还"

## 九、凯恩斯主义的局限与批评

| 批评 | 内容 |
|------|------|
| **滞胀难题** | 1970s 滞胀打破菲利普斯曲线 → 凯恩斯无解 |
| **时滞问题** | 政策制定到生效有长时滞，可能加剧周期 |
| **政治经济学** | 政客爱宽松不爱紧缩 → 逆周期变单边宽松 → 长期通胀/债务 |
| **挤出效应** | 政府借贷可能挤占私人投资（古典批评） |
| **李嘉图等价** | 政府发债=未来税收，理性居民会储蓄，财政无效 |
| **退出无方** | QE 启动易退出难，2022 缩表引发市场震荡 |

---

## 十、一句话总结

> **凯恩斯主义 = 当市场无法自动实现充分就业时，由政府主动管理总需求以稳定经济的学说。它是 20 世纪宏观经济政策的基石——危机时回归、繁荣时被质疑，永远在"干预 vs 自由"的钟摆上。凯恩斯本人不仅给了国内的理论（[[IS-LM模型]]、[[财政政策乘数]]），也给了国际的方案（[[Bancor方案]]、IMF 设计）——后者因 [[布雷顿森林对决]] 失败和 [[IMF治理改革悖论]] 迟迟未落地。**
