# 主权财富基金（Sovereign Wealth Fund, SWF）

> 全球总规模约 USD 12 万亿的国家级长期资本，外汇储备的"分流通道" 或 主权国资的"主动投资载体"

---

## 一、定义与本质

**主权财富基金**（Sovereign Wealth Fund，SWF）是指由**国家政府全资或主要持有**、以**跨代际财富保存或财政稳定**为目的的**专业化投资机构**。

与一般政府投资基金的关键区别：
- **目的**：跨代际（不是当期财政支出）
- **资金性质**：超额储备或自然资源收入
- **投资期**：超长周期（10 年以上）
- **治理**：独立董事会 + 市场化运营
- **披露**：多数受 Santiago Principle 等透明度框架约束

一句话对比：
- **央行外汇储备**：以汇率稳定 + 流动性安全为目标，央行账上
- **主权财富基金**：以收益 + 跨代际为目标，独立机构账上

但二者在实践中经常有交叉：央行将部分多余的外汇储备"分流"到 SWF（典型如中投、GIC、ADIA）。

## 二、三大分类法

### 2.1 按资金来源

```
【1】外汇储备分流型（FX Reserve-funded）
  - 央行外汇储备积累超出国债、流动性等常规需要
  - 转入 SWF 做更高收益的多元化配置
  - 代表：GIC（CIC 部分性质类似）
        ↓
【2】自然资源收入型（Commodity-funded）
  - 石油、天然气、金属矿产的出口收入
  - 为防止"荷兰病"和代际不公，沉淀为 SWF
  - 代表：挪威 NBIM（石油）、ADIA（石油）、俄罗斯 NWF（油气）、阿拉斯加永久基金
        ↓
【3】国有资本管理型（State-owned Equity）
  - 政府分批注入国企股权
  - 由独立机构统一管理，提升市场化运营
  - 代表：淡马锡（新加坡国资）、Mubadala（阿联酋主权投资）、PIF（沙特）
        ↓
【4】财政储蓄型（Fiscal Stabilization）
  - 财政盈余时期积累，赤字时期动用
  - 多数与 SWF 边界模糊（多数 SWF 兼具此功能）
  - 代表：俄罗斯 NWF、哈萨克斯坦 NFRK
```

### 2.2 按治理模式

```
【1】公司型（Corporatized）
  - 私人公司形式，独立董事会
  - 高度市场化、ESG 标准
  - 代表：淡马锡、NBIM、GIC
        ↓
【2】财政部下属型（MoF-attached）
  - 财政部内设机构管理
  - 政策导向明显
  - 代表：中投 CIC（财政部 + 央行双线）、多数发展中国家 SWF
        ↓
【3】央行旗下型（Central Bank-attached）
  - 中央银行内部单位管理
  - 流动性、储备功能优先
  - 多数为外汇储备的延伸（"准 SWF"）
        ↓
【4】特殊立法型（Statutory Board）
  - 议会立法成立、章程严格
  - 议会监管、年报公开
  - 代表：NBIM（挪威央行下设独立法人）
```

### 2.3 按投资风格

```
【1】积极股东型（Active Owner）
  - 派董事、推战略
  - 单笔集中、长期持有
  - 代表：淡马锡、PIF 部分、Mubadala
        ↓
【2】被动配置型（Passive Allocator）
  - 接近指数化、市场化分散
  - ESG 楷模、规则透明
  - 代表：NBIM、APG（荷兰养老金，类似 SWF）
        ↓
【3】政策导向型（Policy-driven）
  - 服务国家战略产业目标
  - 配置保密、回报服务政治目标
  - 代表：中投 CIC（早期风格）、部分俄罗斯 SWF
        ↓
【4】主权财富 + 开发金融混合型（Development Hybrid）
  - 既做 SWF 也做开发贷款
  - 边界模糊
  - 代表：KIA（科威特）、部分 GCC 国家 SWF
```

## 三、Santiago Principle：全球 SWF 透明度框架

### 3.1 起源

```
2007 IMF 报告中提出对 SWF 透明度担忧
        ↓
2008.10 IMF 与 26 个 SWF 在智利圣地亚哥制定 Santiago Principle
        ↓
2008.11 G20 华盛顿峰会背书 Santiago Principle
        ↓
2009 IWG（International Working Group）成立，常设机构
        ↓
实际实施：
  - 截至 2024 年，38 个 SWF 正式签署
  - 中国 CIC 2011 年起加入，但披露深度有限
  - 多数"国有资本管理型" (淡马锡、NBIM) 是范本
```

### 3.2 核心 24 条原则（GAPP 框架）

Santiago Principle 覆盖四大块：

```
【1】法律框架、机构、治理结构（Principle 1-7）
  - 设立目的、目标、政策
  - 治理独立性、董事会结构
  - 风险管理框架
        ↓
【2】政策和投资策略（Principle 8-15）
  - 投资政策的清晰度
  - 与宏观经济政策的协调
  - 投资者关系披露
        ↓
【3】风险管理和投资实践（Principle 16-22）
  - 操作风险、市场风险、信用风险管理
  - 信息披露
  - 合规与外部审计
        ↓
【4】披露原则（Principle 23-24）
  - 年度披露资产配置、回报
  - 关于 SWF 的关键事件和治理变更披露
```

## 五、SWF 与外汇储备 / 央行的关系

### 5.1 三者的功能区分

```
【外汇储备】
  持有者：中央银行
  目的：汇率稳定、流动性安全
  资产形式：以美国国债等高流动性、安全资产为主
  规模：全球合计约 USD 12 万亿（其中 USD 占 ~58%）
        ↓
【主权财富基金】
  持有者：政府全资的独立法人
  目的：跨代际财富保存或财政稳定
  资产形式：股票、另类投资、不动产、直接投资多元化
  规模：全球合计约 USD 12 万亿
        ↓
【开发金融机构】
  持有者：政府下属银行
  目的：基础设施、产业政策、出口支持
  资产形式：长期贷款、股权投资混合
  代表：世界银行、亚投行、中国国家开发银行
```

### 5.2 资金流转通道

```
【标准通道（多数 SWF）】
  央行外汇储备
        |
        | 分流超额部分
        ↓
  SWF 长期投资
        |
        ↓
  全球股票、债券、另类资产
        ↓
  创造跨代际回报

【新加坡模式】
  GIC  = 央行外汇储备分流
  淡马锡 = 国资股权管理
  两个机构互补但不重叠

【中国模式】
  CIC = 财政部 + 央行联合发起
  SAFE Co = 央行旗下
  两个 SWF 都跟外汇储备相关
```

### 5.3 中投（CIC）的特殊性

中投的设立背景是 2000s 中国外汇储备过快积累：
- 2007 年外汇储备已超 USD 1.4 万亿
- 担心储备过度集中于美国国债
- 财政部发行特别国债 1.55 万亿人民币，购汇 USD 2000 亿，作为 CIC 注册资本

CIC 因此是 **"外汇储备分流型 SWF"中最纯粹的代表**之一。

## 六、SWF 的全球金融影响力

### 6.1 总量维度

SWF 占全球股票市场总市值的 10-12%，但其影响力因"主权身份"被放大：

```
SWF 的"非财务影响力"维度：

【1】议价能力
  - 单笔投资可达 USD 数十亿
  - 在 IPO 中作为基石投资人
  - 在跨境并购中可全资收购
        ↓
【2】投票权
  - 派董事席位
  - 影响公司战略
  - 推动 ESG 改革
        ↓
【3】方向信号
  - 加仓行为被市场解读为"国家级看好"
  - 减仓行为被解读为"国家级警示"
  - 因此 SWF 持仓变动的"羊群效应" 显著
```

### 6.2 历史上 SWF 影响市场的案例

```
【1】2007 中投成立
  - 设立本身被市场解读为"美元资产多元化"信号
  - 推动主权基金概念全球流行
        ↓
【2】2008-2009 SWF 反救市
  - 危机中多国 SWF 投资花旗、巴克莱、UBS 等
  - 救市资金超过 IMF 实际贷款规模
        ↓
【3】2013-2017 挪威 NBIM 推动 ESG
  - 在股东大会反对多家公司高管薪酬
  - 推动 BP、Shell 等能源巨头转型披露
  - 引领 ESG 投资全球标准
        ↓
【4】2017 中投减持美国国债
  - 配合中国央行多元化储备
  - 影响美国国债定价
        ↓
【5】2021-2024 PIF 转型沙特愿景
  - PIF 大规模投资 Lucid、奇亚、Activision Blizzard
  - 推动沙特"Vision 2030"经济转型
  - 引发"主权投资 + 国家战略" 模式讨论
```

## 七、SWF 对中国的相关性

### 7.1 中国在 SWF 矩阵中的位置

```
中国 SWF 三大机构：

【1】CIC（中投）
  - 中国对外汇储备的"分流"通道
  - 政策导向 + 央企 + 多元资产
  - 规模 USD 1.35 万亿（仅次于 NBIM）
        ↓
【2】SAFE Co
  - 中国外管局下设的 SWF
  - 高度保密
  - 主要做被动指数化 + 另类投资
        ↓
【3】淡联 / 国新 / 丝路基金等
  - 国资委 + 政策性银行下的"准 SWF"
  - 服务"一带一路"等政策目标
```

### 7.2 与中国机构投资者的差异

```
SWF vs 中国机构资金：

中国社保基金、中投、险资：
  - 部分资金性质类似 SWF（长期、跨代际）
  - 但有更强的"政策性任务"
  - 透明度有限

中国主权基金：中国版"长钱"：
  - 社保基金（2001 起）： 5 万亿+ 人民币，长期股票投资
  - 中投 CIC（2007 起）： 1.35 万亿美元，海外为主
  - 国新 / 诚通 / 淡联，央企股权管理
```

### 7.3 SWF 对 A 股 / 港股的策略含义

SWF 视角下中国资产的 implicit 基准：
- **峰值仓位**：27%（淡马锡 2020 峰值）= "谨慎乐观上限"
- **当前仓位**：16-18% = "中性偏轻"
- **警惕信号**：< 15%

对中国 A 股的含义：
- A 股敞口不在淡马锡口径中（淡马锡基本不投 A 股）
- A 股主要由内资机构长钱支撑（社保、险资、CIC 部分）
- 但全球 SWF 对港股、中概的仓位可以作为一个间接信号

## 八、长期主义 vs 政策导向：SWF 的两种精神

### 8.1 长期主义代表

```
【淡马锡模式】
  - 持股 10-20 年
  - 积极股东、推战略
  - 不卷入党派政治
  - 全球透明度最高的 SWF
        ↓
【挪威 NBIM】
  - 几乎全部被动 + 内部 alpha
  - ESG 全球领袖
  - 议会监管、年报公开
  - 治理品质全球第一
        ↓
【GIC】
  - 3 年发布一次评述
  - 委托外部资管 + 内部直投
  - 风险控制 + 回报稳健
```

### 8.2 政策导向代表

```
【中投 CIC】
  - 服务"外汇储备多元化"目标
  - 早期高调海外投资（百仕通、摩根士丹利等）
  - 后期谨慎 + 多元化
        ↓
【PIF（沙特）】
  - 服务 Vision 2030 经济转型
  - 同时是国内产业基金
  - 兼具主权基金 + 国家战略载体
        ↓
【俄罗斯 NWF】
  - 服务油价波动期的财政稳定
  - 2022 制裁后被冻结部分资产
```

### 8.3 两种精神对策略的影响

```
【长期主义的可借鉴部分】
  - 长周期持仓
  - 公开持仓、接受监管
  - 集中持仓 + 推战略
  - 不卷入党派政治
  - ESG 整合（NBIM 典范）
        ↓
【政策导向的局限】
  - 资金可能因政策急转而变动
  - 透明度不足难以评估 alpha
  - 单笔投资可能受地缘限制
        ↓
【对你的策略含义】
  - 学习"长期主义 SWF" 的持仓哲学
  - 把"政策导向 SWF" 看作"政策性博弈对手"
  - 用 GIC / NBIM 的 3 年评述作为政策资金对市场的"信号灯"
```

## 九、对个人 / 机构投资者的核心启示

### 9.1 把 SWF 当作"机构长钱基准"

```
SWF 持仓变化的解读价值：

【淡马锡】
  - 中国敞口 27% → 16-18% = 顶部信号
  - 加仓印度 = "印度崛起" 主题的机构背书
  - 减某些医药 = 板块顶部信号
        ↓
【NBIM】
  - 减持能源、加仓科技 = 能源板块见顶信号
  - 退出 X 银行 = 该银行治理问题
  - NBIM 的 ESG 否决 = 行业即将出清
        ↓
【GIC】
  - 美国 ~40% 单一最大敞口
  - 增 / 减美国 = "机构长钱"对美国资产的判断
        ↓
【中投 CIC】
  - 持仓完全保密（不便直接参考）
  - 但大方向可推测：减持美债、加仓另类
```

### 9.2 SWF 行为的"反向信号价值"

```
SWF 透明度的差异决定了可参考度：

高透明度的 SWF（可以直接看）：
  - NBIM（每日持仓可见）
  - 淡马锡（年报 + 持仓汇总）
  - GIC（3 年评述）
  - ADIA（年报）
        ↓
低透明度的 SWF（只能间接推断）：
  - CIC（几乎完全保密）
  - PIF（披露有限）
  - 多数发展中国家 SWF
```

### 9.3 "学一半不学一半"

```
【学其持仓理念】
  - 长周期持仓
  - 集中持仓 + 推战略
  - 公开仓位逻辑
        ↓
【学不来其主体】
  - SWF 的"主权身份"附加影响力你无法复制
  - SWF 的"非财务议价能力"你也没有
  - SWF 的"主权级别对手方" 是其特色
        ↓
【把它当作宏观信号】
  - SWF 持仓变动是"机构长钱对全球资产的判断"
  - 不是"你可以直接抄作业的清单"
  - 但可以作为"机构长钱的温度计"
```

## 十、关键术语

| 术语 | 含义 |
|------|------|
| SWF | Sovereign Wealth Fund（主权财富基金） |
| GAPP | Generally Accepted Principles and Practices（圣地亚哥原则全称） |
| Santiago Principle | 2008 年 G20 峰会框架下 SWF 透明度自愿原则 |
| FX Reserve | Foreign Exchange Reserve（外汇储备） |
| MoF | Ministry of Finance（财政部） |
| Central Bank vs SWF | 央行外汇储备 + SWF 长期投资的"分流关系" |
| Dutch Disease | 资源出口繁荣导致本国制造业衰退的"荷兰病" |
| Active Owner | 积极股东，通过董事会推动公司战略 |
| ESG | Environmental + Social + Governance（环境 + 社会 + 公司治理） |
| Stable Ownership | 挪威 NBIM 的核心准则（长期、稳定、有利于公司发展） |

## 十一、一句话总结

> **主权财富基金 = 全球总规模约 USD 12 万亿的国家级长期资本**，按**资金来源**（外汇储备 / 自然资源 / 国资股权）可以分成三大类，按**治理模式**（公司型 / 财政部型 / 央行型）可以分成三种，按**投资风格**（积极股东 / 被动配置 / 政策导向）可以分成三种。
>
> **理解 SWF = 理解五件事**：
> 1. **资金来源决定投资期和资产配置**：外汇储备偏防御、石油基金偏长期、国资股权偏主动
> 2. **Santiago Principle 是全球 SWF 治理品质的下限基线**
> 3. **SWF 与央行的"分流关系"** 是理解其资金性质的关键
> 4. **SWF 持仓变动是"机构长钱对全球资产的判断"**，是高 alpha 信号源
> 5. **SWF 对中国的对应对应中投 + 社保 + 险资** 三个组合
>
> 学习主权财富基金 = 学习一套"国家级长期资金的运作哲学"，对照你自己的"长期主义、分散化、公开化" 三项修炼。
