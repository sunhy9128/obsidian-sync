# QFII（合格境外机构投资者）

## 概述

**QFII（Qualified Foreign Institutional Investor）**——合格境外机构投资者制度，中国资本市场对外开放的第一个正式渠道，于 **2002 年** 启动。境外机构通过资格审批 + 额度管理的方式进入 A 股市场，是中国在资本项目尚未完全开放前提下引入外资的制度创新。

## 关键机制

| 要素 | 说明 |
|------|------|
| 启动时间 | 2002 年（首笔试点 2003 年落地） |
| 管理机构 | 证监会审批资格，外汇局批准额度 |
| 投资范围 | A 股、债券、基金、股指期货（2011 年后逐步放开） |
| 额度管理 | 早期总额度 1500 亿美元；2019 年**取消额度限制** |
| 准入条件 | 境外资产管理机构、银行、保险、证券机构 |
| 资金托管 | 须委托境内托管行（QFII 账户体系） |

## 历史演进

- **2002**：制度启动，初始总额度 40 亿美元
- **2003**：首批 QFII（瑞银、花旗等）获批入市
- **2011**：QFII 额度扩至 300 亿美元，RQFII 同步推出
- **2019**：全面取消 QFII/RQFII 投资额度限制（外汇局）
- **2020**：简化资格审批，扩大投资范围

## 与陆股通的互补

QFII 与[[陆股通]]是外资进入 A 股的两条主通道：

| 维度 | QFII | 陆股通（北向） |
|------|------|---------------|
| 通道类型 | 直接开户 | 互联互通 |
| 托管方式 | 境内托管行 | 港交所中央结算 |
| 交易币种 | 人民币 | 人民币（离岸） |
| 使用场景 | 长线配置、打新、大宗 | 高频交易、指数跟踪 |

## 意义

- **制度破冰**：标志着中国资本市场对外开放的第一步
- **机构化推动**：引入长线外资，改善 A 股投资者结构
- **定价效率**：外资研究能力带动 A 股价值发现（参见 [[A股市场结构]]）
