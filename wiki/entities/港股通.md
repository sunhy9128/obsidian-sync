# 港股通（南向资金）

## 概述

**港股通**——内地资金通过沪深港通**南向**买卖港股的总称，与[[陆股通]]（北向）相对。市场俗称**"南向资金"**，是港股最重要的边际定价力量——2025 年南向净流入逼近 **1.2 万亿港币**（年度历史新高）。

## 关键数据

| 项目 | 说明 |
|------|------|
| 开通时间 | 2014（沪）/ 2016（深） |
| 每日额度 | 420 亿元人民币（南向） |
| 总额度 | 无限制（2018 年取消） |
| 投资门槛 | 个人 50 万资产门槛 |
| 港股外资占比 | 南向资金占港股成交约 40%（主导） |

## 机制要点

- **通道**：内地券商下单 → 经"南向通"接入港交所
- **结算**：人民币结算，港币计价
- **标的范围**：恒生综合指数成分股、港股通标的（含科技、医药、高股息）
- **税制**：港股红利税（H 股 20% 股息税）

## 市场影响

- **港股估值底部支撑**：南向资金持续流入支撑港股估值修复
- **高股息策略载体**：内地资金偏好港股的银行、能源等高股息标的
- **科技股定价**：南向重仓腾讯、美团、小米等，影响港股科技板块

## 历史关键节点

- **2014.11**：沪港通开通，南向同步启动
- **2016.12**：深港通开通，南向扩容
- **2021**：南向净流入创新高（逾 4000 亿港币）
- **2023-2025**：高股息配置潮，南向持续大额净流入
