# 挪威主权基金（NBIM / GPFG）

> 全球最大主权财富基金，1990 年成立，石油收入"代际公平"沉淀，USD 1.7 万亿规模，**被动 + ESG 楷模，全球透明度第一名**

---

## 一、定义与定位

**挪威主权基金**（正式名称 Government Pension Fund Global，GPFG）成立于 **1990 年**，由**挪威央行下设的 Norges Bank Investment Management（NBIM）** 管理，是挪威"石油收入代际公平"沉淀机制的载体。

世界唯一一家以石油收入为核心、规模超过 USD 1.7 万亿的 SWF，规模相当于全球第 4-5 大股票持有者（按个股市值口径不同而波动）。

GPFG 的根本哲学：**"代际公平"**，防止当代人挥霍石油资源，沉淀为长期资产服务挪威未来世代。

## 三、治理结构

### 3.1 法律架构

```
挪威王国
    |
    | 议会（Storting）立法设立 GPFG
    ↓
挪威财政部（MoF）
    | 制定投资政策细则
    ↓
挪威央行（Norges Bank）
    |
    | 央行旗下独立法人
    ↓
Norges Bank Investment Management（NBIM）
    | CEO + 投资团队 + 风险 + 合规
    ↓
GPFG（基金本体）
    |
    ↓
全球 7,000+ 公司股票 + 债券 + 不动产
```

### 3.2 治理特色

```
【1】三权分立式治理（议会 / 财政部 / 央行 / NBIM）
  - 议会：立法定下"投资原则白皮书"
  - 财政部：每年修订"投资策略白皮书"
  - 央行下设 NBIM：日常运营
  - NBIM CEO 由央行行长提名，议会通过
        ↓
【2】治理哲学
  - "稳定所有权"（Stable Ownership），NBIM 是"好的长期股东"
  - "不卷政治"，在股东大会只关注财务、ESG 议题，不试图控制公司
  - "公开透明"，所有持仓每日公开（每季度详细披露）
        ↓
【3】价值基线
  - "财政锚"，每年动用基金**实际回报的 3%** 进入财政支出
  - 通胀调整：基金实际购买力不下降
  - 这条"财政锚" 是 NBIM 治理模式的核心
```

## 四、资产配置：70% 权益 / 27% 债券 / 3% 不动产

### 4.1 政策组合

```
NBIM 政策组合（2024 年目标）：

  权益（股票）：72%
  固收（债券）：26%
  不动产：2%（持续增配中，目标 5%）
  其他：~0%

特点：
  - 这是"被动偏多" 的极致，权益占比超过其它 SWF
  - 在全球上市公司中持有 ~1.5% 股权
  - 70% 权益是为了对冲"长期通胀 + 实际回报" 
```

### 4.2 地理与行业分布

```
地理（2024 年）：

  美国：~55%
  欧洲：~25%
  亚太：~13%
  其他新兴：~7%

行业（2024 年前 5）：

  科技：~22%（Apple、Microsoft、Alphabet、ASML、Nvidia）
  金融：~17%
  工业：~12%
  消费：~12%
  健康：~10%
```

### 4.3 长期回报

```
NBIM 25 年（1998-2023）实际回报：

  - 5.8% 年化（USD 计）
  - 1998-2024 累计回报 7.5% 年化（USD 计）
  - 这是全球 SWF 中"长期 + 稳定" 的代表
  - 与 GIC 的 4.4%、淡马锡的 6% 相当
        ↓
关键特征：
  - 20+ 年区间里从未出现" 连续 2 年负回报"（除了 2008 和 2022）
  - 这是被动型 SWF 的精髓，长期指数化 + 内部 alpha 微调
  - 失去大行情的 alpha（如科技暴涨），但减少大熊市的跌幅
```

## 五、ESG 楷模：全球最强主权基金

### 5.1 ESG 历史

```
NBIM 的 ESG 发展：

【2004】
  - 发布"道德准则"（Ethical Guidelines）
  - 排除烟草、人地雷、核武器等特定行业
        ↓
【2009】
  - 在股东大会投票反对部分高管薪酬
  - 推动气候披露要求
        ↓
【2015 巴黎气候协议后】
  - 强制要求投资组合公司披露气候风险
  - 推动"气候行动计划"
        ↓
【2017-2019】
  - 从煤炭行业全面撤资
  - 建立"风险敞口跟踪"
  - 在 ExxonMobil、Chevron 等推动能源转型
        ↓
【2020-2024】
  - ESG 整合成为投资决策核心
  - 推动"自然风险、生物多样性" 议题
  - 在 ESG 评级机构议题上保持独立性
```

### 5.2 ESG 投票影响力

```
NBIM 每年参与 10,000+ 股东大会，议题包括：

  - 反对过高高管薪酬
  - 推动气候披露
  - 推动多元化
  - 反对反 ESG 措施
  - 反对不当 ESG 报告
        ↓
关键案例：
  - 推动 ExxonMobil 任命董事（前高盛高管）
  - 推动 Shell 加快能源转型
  - 反对 ARAMCO 上市的不透明披露
        ↓
意义：
  - NBIM 的"投票影响力" 超过" 美元仓位" 本身
  - 全球 SWF 中最善于用"被动持股 + 主动投票" 推动变革
```

## 六、NBIM vs 淡马锡 vs GIC vs CIC

### 6.1 横向对比

| 维度 | NBIM | 淡马锡 | GIC | CIC |
|------|------|--------|-----|-----|
| 规模 (USD t) | 1.7 | 0.29 | 0.77 | 1.35 |
| 资金来源 | 石油 | 国资股权 | 外汇储备 | 外汇储备 |
| 持股集中度 | 极分散（7,000+ 公司） | 集中 | 中度分散 | 不公开 |
| 投资风格 | 被动 + ESG | 积极股东 | 被动偏多 | 政策导向 |
| 治理 | 三权分立（议会 / 财政部 / NBIM） | 财政部独立 | 财政部独立 | 国务院直管 |
| 透明度 | 最高（每日持仓公开） | 高（年报） | 中（3 年评述） | 低 |
| ESG 强度 | 极致 | 中等 | 中等 | 弱 |
| 政治独立性 | 较高 | 较高 | 较高 | 较低 |

### 6.2 四大 SWF 精神对比

```
NBIM（被动 + ESG 极致）
  - 70% 权益、近乎指数化
  - ESG 是核心议题
  - 治理上"议会 + 财政部 + NBIM" 三权分立
  - 投资哲学 = "稳定所有权 + 长期视角"
        ↓
淡马锡（积极股东）
  - 重权益、单笔集中
  - 几乎不投固收
  - 不管 ESG（"我们做生意，不是做慈善"）
  - 投资哲学 = "积极股东 + 推战略"
        ↓
GIC（被动偏多）
  - 高度分散
  - 接近 NBIM 但更灵活
  - 较少 ESG 推动
  - 投资哲学 = "分散化 + 委托外部资管"
        ↓
CIC（政策导向）
  - 多元配置
  - 服务中国战略意图
  - 透明度低
  - 投资哲学 = "外汇储备多元化 + 跨境产业布局"
```

## 七、历史脉络

### 7.1 石油收入的代际公平沉淀

```
1969 北海发现石油
        ↓
1970s-1980s 石油收入快速增长
        ↓
1990 议会通过 GPFG 决议
  - 把石油收入沉淀为 SWF
  - 防止荷兰病、保护代际公平
        ↓
1996 首笔资金注入（USD 1 亿）
        ↓
1998 NBIM 成立，开始投资
        ↓
2000s 权益占比从 40% 逐步上升至 70%
        ↓
2010s 规模突破 USD 5000 亿 → 1 万亿
        ↓
2017 进一步治理改革，NBIM 在央行下相对独立
        ↓
2020s 突破 USD 1.5 万亿，ESG 整合深化
        ↓
2024 突破 USD 1.7 万亿（全球最大 SWF）
```

## 八、对全球金融市场的影响力

### 8.1 持有比例与议价能力

```
NBIM 持股的特殊地位：

【1】Apple 持股
  - ~1.5% 股权
  - 第四 / 第五大股东
  - 每年股东大会投票足以影响决议
        ↓
【2】Microsoft、Alphabet、Amazon、Nvidia 等
  - 持股比例 0.5-1%
  - 但绝对值巨大
        ↓
【3】欧洲大型公司
  - Novartis、Nestlé、ASML、LVMH、Siemens、SAP 等
  - 持股超过 2-5% 的多家公司
        ↓
【4】意义
  - NBIM 是全球单一最大被动持股者之一
  - 通过"投票但不试图控制" 推动公司治理改革
```

### 8.2 关键市场影响案例

```
【1】2015 Tesla 增持
  - 当时 NBIM 持股突破 USD 100 亿
  - 提振市场信心
        ↓
【2】2017 煤炭撤资
  - 全球 SWF 中动作最大
  - 推动煤炭公司估值大幅调整
        ↓
【3】2022 退出能源股
  - 短期内推动能源板块抛售
  - 但被市场快速吸收
        ↓
【4】年度股东大会投票
  - 每年投出的 10,000+ 票
  - 反对方提案往往被其它大机构跟随
```

## 十、一句话总结

> **挪威主权基金（NBIM / GPFG）= 全球最大 SWF**：USD 1.7 万亿规模，1990 年石油收入沉淀机制，议会立法 + 财政部主管 + 央行旗下 NBIM 运营，**70% 权益 + 26% 债券 + 4% 不动产** 的"被动偏多 + ESG 极致" 典范。
>
> 它跟淡马锡（积极股东）、GIC（被动偏多）、CIC（政策导向）并列为 SWF 矩阵的四大代表，各自代表 SWF 的一种精神：**NBIM = 透明度极致的"被动 + ESG" 模式**。
>
> NBIM 持股遍布全球 7,000+ 公司，是全球**单一最大被动持股者之一**。它通过"被动持股 + 主动投票" 推动全球 ESG 改革，是主权基金中"积极被动" 的最优雅实现，自身不试图控制公司，但用投票权推动变革。
>
> **理解 NBIM = 理解三件事**：
> 1. **石油基金的"代际公平" 沉淀机制**，防止荷兰病、保护未来世代
> 2. **被动持股 + ESG 整合**，极高效率 + 治理推动力
> 3. **议会 / 财政部 / NBIM 三权分立**，治理结构对资金政治化的最优防御
>
> 学习 NBIM 的"被动 + 透明 + ESG" 三件套 = 学习机构长钱"被动投资的极致"。
