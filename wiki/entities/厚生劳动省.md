# 厚生劳动省（Ministry of Health, Labour and Welfare）

> 日本"花钱最多"的省厅——掌管医疗、年金、劳动、少子化四大块,年预算占日本一般会计约1/3。
> 它是[[安倍经济学]]"新三支箭"(生育率1.8/女性就业/护理离职零)的**执行者**,
> 也是[[大藏省]](财务省)预算博弈中的**头号对手**。

---

## 一、基本信息

| 项目 | 内容 |
|------|------|
| **名称** | 厚生劳动省（Ministry of Health, Labour and Welfare, MHLW） |
| **成立时间** | 2001年1月6日(中央省厅改革,厚生省+劳动省合并) |
| **前身** | 厚生省(1938-2001)、劳动省(1947-2001) |
| **性质** | 日本主管医疗卫生、劳动就业、社会保障的最高行政机关 |
| **职能范围** | 年金、医疗保险、介护保险、劳动政策、雇佣保险、卫生防疫、少子化对策、生活保护 |
| **预算规模** | 2024年度一般会计预算约35.6万亿日元,为**日本最大支出省厅**(约占一般会计预算1/3) |
| **本省所在地** | 东京都千代田区霞关(与财务省、大藏省旧址同区域) |

## 二、历史沿革

### 2.1 前身之一:厚生省(1938-2001)

- **1871年**:前身可追溯至内务省卫生局
- **1938年1月11日**:厚生省独立设立——战时**国民动员**需求(征兵体检、军人抚恤、粮食配给)催生
- **战后**:接管医疗、保险、社会福利,成为日本"福利国家"的承载部门
- 主导建立 **国民皆保险(1961年)**、国民年金(1961年)、老人医疗免费化(1973年)等制度

### 2.2 前身之二:劳动省(1947-2001)

- **1947年**:劳动省设立,主管劳动基准、职业安定、雇佣保险(1974年)、劳动灾害保险
- 主导**春斗**(春季劳资谈判)的制度环境

### 2.3 合并:2001年1月6日

桥本行政改革(1996-2001)将 1府22省厅 压缩为 1府12省厅:
- 厚生省 + 劳动省 → **厚生劳动省**
- 同时期:大藏省 → 财务省(分出金融监管权给金融厅)
- 合并动因:少子老龄化下"医疗+年金+雇佣"需要一体统筹

## 三、主要职责(四大板块)

### 3.1 社会保障(最大头)

| 制度 | 内容 | 覆盖/规模 |
|------|------|-----------|
| **厚生年金** | 受雇者养老金(与国民年金双层结构) | 参保约7000万人 |
| **国民年金** | 自营业者/无业者基础年金 | 覆盖全体20-60岁国民 |
| **健康保险** | 受雇者医疗险(协会健保/组合健保) | 约7000万人 |
| **国民健康保险** | 自营业者/退职者医疗险 | 约3000万人 |
| **后期高龄者医疗** | 75岁以上老人医疗 | 约1800万人 |
| **介护保险** | 65岁以上需护理者服务 | 2000年创设,约700万人 |
| **生活保护** | 最低生活保障 | 约200万户 |

> 社保给付费总额:2022年度约**133万亿日元**,占GDP约21%——全球主要经济体中最高的社会福利负担之一。

### 3.2 劳动政策

- **劳动基准**:法定劳动时间、最低工资(全国加权平均2024年约1055日元/小时)
- **雇用保险**:失业给付、雇用调整助成金
- **劳资关系**:春斗的行政支持方(2024年春斗涨薪5.28%,创33年新高,直接由厚劳省公布)
- **劳动统计**:每月勤劳统计调查——**实际工资数据的官方发布者**(安倍经济学期间实际工资连跌的"官方记录者")

### 3.3 少子化对策(安倍经济学新三支箭核心执行地)

- **儿童补贴**:0-15岁儿童每人月1万-1.5万日元(2024年扩大)
- **保育**:待机儿童解消、保育士待遇改善
- **结婚/生育支援**:2023年创立"儿童未来战略"、异次元少子化对策(岸田时期预算翻倍计划)
- 但效果存疑:总和生育率从2012年的1.41跌至**2023年的1.20**(厚劳省自己发布)

### 3.4 卫生防疫

- 传染病对策(新冠期间的指挥中枢之一)
- 医药品、医疗器械、食品卫生、国民营养

## 四、与金融知识库主线的关联(核心)

### 4.1 与大藏省/财务省的"钱"的博弈

厚生劳动省是日本财政的**头号支出部门**,与管钱的[[大藏省]]形成结构性博弈:

```
大藏省(1869-2001) / 财务省(2001-):  管预算、管税、管国债 → "收钱的管家"
厚生劳动省(2001-):                 管社保支出、年金、医疗 → "花钱的大户"
```

- **社保支出是日本一般会计预算的最大项目**(约1/3),财务省每年编制预算时都要与厚劳省讨价还价
- **消费税增税(2014:5%→8%、2019:8%→10%)**:官方说法是"充实社会保障财源"——财务省收上来的税,厚劳省花出去
- **国债依存度**:社保缺口持续推高日本国债发行,与[[日本财政扩张担忧]]直接相关
- 安倍经济学"第二支箭"与社保的关系:财政扩张的很大一部分实际上流向了社保(少子化+老龄化),不是基建

### 4.2 与安倍经济学"新三支箭"的关系(2015)

安倍2015年提出的新三支箭,有两支半要靠厚生劳动省执行:

| 新三支箭 | 目标 | 执行主体 |
|----------|------|----------|
| 名义GDP 600万亿 | 2020年达成 | 宏观经济整体 |
| **合计特殊出生率1.8** | 2020年达成 | **厚生劳动省(少子化对策)** |
| **护理离职零** | 2020年达成 | **厚生劳动省(介护+劳动)** |
| (附)女性就业率73% | 2020年达成 | **厚生劳动省(劳动政策)** |

**实际结果(2020年验收):**
- 出生率:1.20(2023),**远低于1.8目标,且比2012年的1.41还低**——新三支箭最大败绩
- 护理离职:未清零
- 女性就业率:女性25-44岁就业率2012年65.8%→2022年79.5%——**少有的达标项**

### 4.3 实际工资"官方记录者"

安倍经济学最大的失败标志——实际工资2012-2022累计**-8%**:
- 数据来源就是厚生劳动省的《每月勤劳统计调查》
- 2024年3月退出负利率后,厚劳省公布的春斗涨薪(2024年5.28%)成为"工资-通胀螺旋"能否建立的关键观察指标

### 4.4 年金与国债市场

- 厚生年金积立金由**年金积立金管理运用独立行政法人(GPIF)**运营(约226万亿日元,全球最大养老基金)
- GPIF大量配置日本国债——是[[日本银行]]国债"债化"体系外的另一大玩家
- 财务省/日银/GPIF/厚劳省四者构成了日本"国债-年金-央行"三角结构

## 七、平行案例(国际对比)

| 国家 | 对应机构 | 特点 |
|------|----------|------|
| 中国 | 人力资源和社会保障部(2008-) | 人社部+卫健委分设,社保与医疗分离 |
| 美国 | HHS(卫生)+DOL(劳动) | 分设,无统一社保部 |
| 英国 | 卫生部(DHSC)+DWP(工作与养老金) | 分设 |
| 德国 | 联邦劳动与社会事务部(BMAS) | 与日本最接近——社保+劳动一体化 |
| 法国 | 劳动、卫生与团结部(2024- ) | 合并制 |

> 日本模式的特点:**
> 少子老龄化最先爆发、社保负担最重、预算占比最高 → 厚劳省权力极大;
> 但"花钱部门"与"收钱部门"(财务省)的长期博弈,也是日本财政赤字的结构性来源之一。**

## 八、一句话总结(老王版)

> **大藏省管"收钱",厚生劳动省管"花钱"——日本财政的一对冤家。
> 安倍经济学第三支箭(结构改革)没射出去,新三支箭的生育率目标又惨败(1.20 vs 1.8),
> 而厚劳省正是这场败绩的第一线。日本财政的未来,一半押在这栋霞关大楼的预算案上。**
