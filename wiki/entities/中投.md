# 中投公司（CIC）

> 中国最大的主权财富基金，2007 年由财政部 + 央行联合发起的"外汇储备分流"型 SWF，规模 USD 1.35 万亿，**全球透明度最低**的大型 SWF

---

## 一、定义与定位

**中国投资有限责任公司**（China Investment Corporation，CIC）成立于 **2007 年 9 月 29 日**，总部位于北京，是**中国国务院直接管辖的国有独资公司**，注册资本金 2000 亿美元（首期由财政部发特别国债 1.55 万亿人民币购汇注入）。

设立的根本背景：**2000s 中国外汇储备过快积累**，到 2007 年中已超 USD 1.4 万亿，过度集中于美国国债，引发"外汇储备多元化 + 跨代际财富保存"双重诉求。

CIC 是 SWF 矩阵中**最大的"外汇储备分流型" SWF**之一（仅次于 NBIM），也是透明度最低、政策色彩最浓的。

## 三、治理结构

```
国务院
   |
   | 国有独资公司，直接监管
   ↓
董事会（11 人）
   - 董事长（兼党委书记）
   - 副董事长 + 执行董事
   - 外部董事（含外资知名人士）
   - 职工董事
        ↓
管理层
   - 总经理
   - 投资官 + 风险官
   - 海外子公司（中投国际 CIC International）
```

### 3.1 历史 CEO

- 高西庆（2007-2012，首任 CEO，搭建架构）
- 丁学东（2012-2013）
- 李克平（2013-2017，金融机构背景）
- 彭纯（2019-2023，原交通银行行长）
- 张青松（2024 至今，原中国进出口银行行长）

### 3.2 与央行的关系

CIC 的法律结构相对特殊：
- 财政部发特别国债购汇 → 作为 CIC 注册资本
- 央行在外汇操作上提供流动性支持
- 国务院直接管辖（绕过财政部日常）
- 这是"财政部 + 央行联合发起" 但"国务院直接管辖"的特殊安排

## 四、资产配置与投资风格

### 4.1 多年大类配置（年报口径）

```
CIC 多年大类资产配置比例（2015-2023）：

  公开市场股票：~30-40%
  固定收益：~25-35%
  另类投资（PE、不动产、基础设施）：~25-35%
  现金：~5%
  其他：~5%

特点：
  - 比 GIC 更激进（另类配置更高）
  - 比淡马锡更分散（含固收）
  - 接近 NBIM（被动 + 多元）
```

### 4.2 投资风格

```
【1】政策导向（Policy-driven）
  - 服务"外汇储备多元化" 任务
  - 服务"一带一路" 投资
  - 服务央企跨境并购
        ↓
【2】保密性较高（Low Transparency）
  - 持仓完全保密
  - 年报披露大类资产配置
  - 不披露具体持仓明细
  - 在 Santiago Principle 框架中透明度偏弱
        ↓
【3】重央企跨境角色（Strategic）
  - 2007-2009 早期高调（入股百仕通、摩根士丹利）
  - 后期趋于低调
  - 部分通过子公司"中投国际"做全球直投
        ↓
【4】长期视角但非纯长钱
  - 投资期实际超过 15 年
  - 但受政策周期影响较大
  - 不像淡马锡 / NBIM 那样"完全脱离政治"
```

### 4.3 关键投资案例

```
【1】早期海外大额投资（2007-2010）
  - 50 亿美元入股百仕通（Blackstone）IPO
  - 100 亿美元入股摩根士丹利
  - 与新加坡淡马锡合作入股巴克莱
  - 10 亿入股美国国债基金
        ↓
【2】大宗资源 / 基础设施
  - 多家能源矿产（澳洲、非洲、南美）
  - 港口、电网（如东方海外 OOCL）
  - 与中投海外平台配合
        ↓
【3】PE 间接配置
  - 大规模投资 Blackstone、KKR、Carlyle 等 PE 巨头基金
  - 2017-2024 PE 间接投资持续增加
        ↓
【4】"一带一路" 投资
  - 通过丝路基金、淡联企业等政策性基金
  - 服务战略，与 CIC 主账户部分重叠
```

## 五、与淡马锡、GIC 的关键区别

### 5.1 矩阵对比

| 维度 | 中投 CIC | 淡马锡 | GIC |
|------|----------|--------|-----|
| 成立 | 2007 | 1974 | 1981 |
| 资金来源 | 外汇储备分流 | 国有股权 | 外汇储备分流 |
| 规模 | USD 1.35 t | USD 289 b | USD 770 b |
| 治理 | 国务院 + 财政部 + 央行混合 | 财政部独立董事会 | 财政部独立董事会 |
| 透明度 | 低 | 高 | 高 |
| 持仓是否公开 | 否 | 是 | 是 |
| 资产配置 | 多元（权益 + 固收 + 另类） | 重权益 | 多元分散 |
| 投资风格 | 政策导向 + 跨境 | 积极股东 + 主动 | 被动偏多 |
| 与政治关系 | 紧密（国务院直管） | 较独立 | 较独立 |

### 5.2 三大核心区别

```
【资金性质】
  CIC = 财政部 + 央行"联合发起"（外汇储备分流）
  淡马锡 = 政府注入"国资股权"
  GIC = 央行外汇储备超额部分
        ↓
【治理透明度】
  CIC = 持仓完全保密，无法外部评估 alpha
  淡马锡 = 年报 + 持仓汇总，最透明 SWF 之一
  GIC = 3 年评述，定时信息披露
        ↓
【与政治关系】
  CIC = 国务院直管，跟一国政策目标紧密绑定
  淡马锡 = 财政部下设，但董事会多数独立董事
  GIC = 类似淡马锡，相对独立
```

## 六、历史脉络

### 6.1 创立动机

```
2003-2007 中国外汇储备快速增长：
  - 2003：USD 4030 亿
  - 2005：USD 8189 亿
  - 2007.6：USD 1.33 万亿（首次超过日本成全球第一）
        ↓
担忧：
  - 美元贬值风险
  - 美债过度集中
  - 央行动用外汇储备对冲汇率波动的弹药有限
        ↓
讨论：
  - 2003-2006 央行外汇储备调整方案多次酝酿
  - 央行 + 财政部对资金用途存分歧
  - 2006-2007 政治协调，最终设立独立法人
        ↓
2007.9.29：中投正式成立
  - 首期注册资本 2000 亿美元
  - 财政部发特别国债 1.55 万亿人民币，购汇注入
  - 借鉴淡马锡 + 挪威模式，但中国特色调整
```

### 6.2 关键阶段

```
【2007-2010 高调期】
  - 50 亿入股百仕通
  - 100 亿入股摩根士丹利
  - 中投海外投资规模一年数十亿
        ↓
【2011-2014 调整期】
  - 2008-2010 全球金融危机，部分投资浮亏
  - 调整为更分散、更长期
  - 强调"机构化、市场化、专业化"
        ↓
【2015-2020 多元化期】
  - 增加 PE 间接投资
  - 拓宽行业（科技、医疗、消费）
  - 关注 ESG 与可持续发展
        ↓
【2021-2024 地缘调整期】
  - 中美科技摩擦加剧
  - 部分美元资产受到监管审查
  - 增加欧 / 亚 / 新兴市场
```

## 七、对中国市场的策略含义

### 7.1 与 A 股 / 港股的间接关联

```
CIC 对 A 股 / 港股的直接敞口：

【1】直接持有 A 股：
  - 实际很少（CIC 主要做海外投资）
  - 但通过子公司有少数 A 股投资
        ↓
【2】持有港股：
  - 较多（中概互联）
  - 但口径不公开
        ↓
【3】通过"中投海外平台"：
  - 部分回流境内/香港做 PE
  - 但相比社保、险资规模有限
        ↓
对你的策略含义：
  - CIC 不是 A 股主要"长钱"（主要是社保、险资）
  - CIC 持仓不公开，不能作 alpha 信号源
  - CIC 政策动作是"信号灯"，不是"资产配置的方向"
```

### 7.2 间接信号价值

```
CIC 不是 alpha 信号源，但是 "政策方向信号灯"：

CIC 政策动作：
  - 加仓某些行业（如科技、新能源）= 政策导向
  - 通过子公司加大人民币资产配置 = 看好中国
        ↓
对你的策略含义：
  - CIC 透明度不足，不能作为 alpha 基准
  - 但 CIC 报告 + 公告中的措辞可以反映"政策方向"
  - 适合作为"政府意图解读"，不适合作为"机构资金判断"
        ↓
更直接的 alpha 信号（透明度好）：
  - NBIM、淡马锡、GIC 的公开披露
  - 社保基金年度报告（含 5 年累计回报率）
  - 险资权益持仓季报
```

## 九、一句话总结

> **中投（CIC）= 中国外汇储备"分流通道" + 全球第二大 SWF**，2007 年成立，财政部 + 央行联合发起（实际由国务院直管），注册资本 2000 亿美元起，现已扩张至 USD 1.35 万亿规模。
>
> CIC 是 SWF 矩阵中**透明度最低、政策色彩最浓**的一家，持仓完全保密，外部无法验证 alpha；资金用途受国务院直接管辖，**不完全脱离政治**，与淡马锡 / NBIM 这种"学术型 SWF" 不同。
>
> 它不像淡马锡 / GIC 那样提供"机构长钱的 alpha 信号"，但它提供了 **"中国政策意图的解读"** 价值，通过年度报告与重大公告，可以读出"外汇储备多元化、跨境产业升级"等政策方向。
>
> **理解 CIC = 理解三件事**：
> 1. **中国外汇储备的"分流通道"**，从央行超额储备分流到独立 SWF
> 2. **"国家资本主义"的当代版本**，政府管股权，独立机构管运营，但严控透明度
> 3. **透明度低的代价**，市场无法验证 CIC 的 alpha，长期影响其国际信誉
