# 淡马锡（Temasek Holdings）

> 新加坡两大主权财富基金之一（与 GIC 并列），全球透明度最高的"积极股东型"长期资本

---

## 一、定义与定位

**淡马锡控股**（Temasek Holdings Pte. Ltd.）成立于 **1974 年 6 月 25 日**，总部位于新加坡，是**新加坡共和国财政部的全资子公司**，以私人有限公司形式独立运作。

核心定位：
- **主权投资机构（SWF）**：管理新加坡国有资本组合
- **与 GIC 并列但分立**：GIC 管理**外汇储备**（偏固收+多资产配置），淡马锡管**国有资产股权**（偏权益+长期主动持有）
- **"积极股东 + 长周期"模式**：不受季度排名压力影响，持股 10 至 20 年是常态
- **圣地亚哥原则（Santiago Principle）成员**：G20/IMF 框架下的 SWF 透明度自愿标准，持仓年报公开可查，是全球最透明的 SWF 之一

与同类 SWF 的本质区别：
- **中投（CIC）**：中国财政部 + 央行发起的"外汇储备分流"型 SWF（2007 成立）
- **GIC**：新加坡"外汇储备管理"型 SWF
- **淡马锡**：新加坡"国有资产主动管理"型 SWF
- **挪威主权基金（NBIM）**：挪威"石油基金"型 SWF，权益+固收平衡
- **ADIA（阿联酋）**：石油基金被动型 SWF
- **淡马锡的独特之处**：五家里最像"PE 控股公司"，不是被动配置，是主动选股+派董事+推战略。

## 三、治理结构

### 3.1 股东与董事会

```
新加坡共和国财政部（100% 持有）
        |
        |  治理，不干预日常经营
        ↓
淡马锡董事会（~13 人）
  - 主席 + CEO（部分时期兼任）
  - 财政部代表
  - 独立董事占多数（政商学界资深人士）
        ↓
管理层
  - CEO + CIO + 多个区域/行业 MD
```

历史 CEO：
- Ng Kok Song 吴国森（1994-2003），建立专业资管团队
- Ho Ching 何晶（2004-2021，前总理李显龙夫人），扩张海外、中国加仓
- Dilhan Pillay（2021 至今），地缘再平衡

### 3.2 抗政治化的防火墙

淡马锡模式的"治理品质"是它区别于多数 SWF 的核心：

```
【治理透明】
  - 年度回顾（Annual Review）每年公开
  - 财务报表按国际标准披露
  - 在新加坡国会接受质询
        ↓
【专业运营】
  - 董事会多数独立董事
  - 管理层多为职业资管人士
  - 不卷入党派政治
        ↓
【与同类对比】
  - 中投 CIC：完全保密，无法对比基准
  - 挪威 NBIM：透明但属"被动 + ESG"风格
  - GIC：3 年发布一次评述，组合汇总披露
  - ADIA：年报公开，组合层面披露
  - 淡马锡：年报 + 持仓口径，相对最接近"上市公司"的标准
```

Santiago Principle 框架（2008 年 G20 峰会发布）把淡马锡列为治理标杆。

## 四、投资哲学：长钱 + 积极股东 + 不靠市场预测

### 4.1 三大铁律

```
【1】长周期（Long-term horizon）
  - 持股 10 到 20 年是常态
  - 不被季度财报、宏观噪音左右
  - 在别人恐惧时加仓是核心策略
        ↓
【2】积极股东（Active investor）
  - 派董事入持仓公司董事会
  - 参与战略方向、CEO 选择、并购取舍
  - 持仓集中度显著高于被动资管
        ↓
【3】不做市场时点判断（Not market timing）
  - 不搞 60/40、All-weather、Risk Parity
  - 不持大笔现金等恐慌时刻
  - 增量资金持续投入，组合长期高仓位
```

这三条铁律衍生出一个关键特征：**淡马锡的"业绩压力"被锁在 10 年以上周期，短期波动对它无意义。**

### 4.2 行业与地区偏好（2024 年报）

地区分布（按 NAV 占比）：
- 新加坡本土：~25%（旗舰 DBS、Singtel、SIA、CapitaLand）
- 中国大陆 + 港股：~16-18%（详见第五章）
- 北美（美 + 加）：~30%
- 欧洲：~12%
- 东南亚（除新加坡）：~8%
- 其他亚太（印、日、韩）：~6%
- 其他：~3%

行业（自下而上看重）：
- 金融服务（20%+，含 DBS、渣打、ICICI Bank、汇丰）
- 科技 + 互联网（高权重，含蚂蚁、阿里、京东、Meta、Microsoft、特斯拉早期）
- 生命科学（药明、Innovent、Regeneron 等）
- 消费升级（中国消费 + 东南亚消费）
- 新能源 + 出行（特斯拉、宁德时代、VinFast）

非上市 / PE / VC 暴露：通过淡马锡旗下机构（淡联企业、Pavilion Capital 等）做 VC，单笔通常 USD 50m 至 300m 量级。

### 4.3 长期回报：风险调整后跑赢指数

```
10 年 TSR（2014-2024）分解：

  - 6% 年化（含新元升值对冲后）
  - 同期 MSCI ACWI 年化 ~7.5%（含汇率）
  - 略输指数，但风险调整后 Sharpe 显著更高
        ↓
关键解读：
  - 10 年回报被 2018-2022 中国资产回撤拖累
  - 2013-2017 周期，淡马锡领先指数（长钱抄底阿里腾讯）
  - 在熊市抗跌、牛市跟得上，是机构长钱的标准风格
```

> 关键判断：淡马锡"略输指数"恰恰是长期主义的证据。它不通过加杠杆、加集中度来放大回报，偏好风险调整后回报。这种风格对**机构投资者而非散户最具参考价值**。

## 五、中国敞口：从 27% 到 16% 的演变

这是淡马锡**最具策略参考价值**的数据。它相当于一份"成熟长钱"对中国资产的 implicit 仓位基准。

### 5.1 历年敞口轨迹

```
淡马锡中国敞口（中国大陆 + 港股，按 NAV 占比）：

2010-2013：13-16%
  - 加仓过程中，但海外机构对中国仍有疑虑
        ↓
2014-2017：16-20%
  - 沪港通前后加大 H 股配置
  - 重仓蚂蚁、京东、顺丰、药明
        ↓
2018-2020：峰值 27%
  - 2018 熊市末期加仓
  - 重仓药明、宁德、中国平安
        ↓
2021-2023：回落 19-16%
  - 反垄断、共同富裕、地缘风险升级
  - 减持部分科技股
        ↓
2024-2025：16-18%
  - 加回港股（互联网 + 电动车）
  - A 股暴露仍偏低
```

### 5.2 标志性持仓案例

```
【1】蚂蚁集团（2018 前后入股，pre-IPO 估值高峰）
  - 账面回报一度达 8-10 倍
  - 2020.11 IPO 暂停后大幅回撤
  - 2020-2022 业绩压力的主要来源
        ↓
【2】京东物流、菜鸟网络
  - 物流领域系统化布局
  - 受益 2018-2021 中国电商爆发
        ↓
【3】药明康德、药明生物（CXO 双子）
  - 全球 CXO 龙头的组合持仓
  - 2020-2022 回报翻 2-3 倍
  - 2024 之后随美国 BIOSECURE 类法案回撤
        ↓
【4】顺丰、宁德时代
  - 高端制造代表持仓
        ↓
【5】汇川技术、新时达
  - 工业自动化押注
        ↓
【6】阿里巴巴、京东
  - 互联网平台抗周期持仓
```

### 5.3 解读：对策略的含义

```
为什么这条基线对策略重要：

【1】作为"机构长钱"对中国资产的风险溢价参考
  - 27%（峰值） = "谨慎乐观上限"
  - 16-18%（当前） = "中性偏轻"
  - < 15% = 明显警惕信号
        ↓
【2】单一新兴市场上限
  - 淡马锡对单一新兴市场的 implicit 上限约 25-30%
  - 配合新加坡本土 25%，亚太合计 ~50%
        ↓
【3】地缘对冲视角
  - 中国敞口从 27% 回落到 16% 期间，加仓北美（特斯拉、Microsoft、Meta）
  - 这是主权机构调整中的典型"分散化"案例
        ↓
【4】对个人投资者的指引
  - 你的核心组合中国仓位建议区间：15-25%
  - 超过 27% 的仓位已经超过"最优长钱"上限
  - 进入低 15% 区间 = 机构资金也在警示风险
```

## 六、历史脉络：1974 至今

### 6.1 阶段划分

```
【本土阶段 1974-1990】
  - 几乎全部为新加坡国企
  - DBS、SIA、Singtel、Keppel 等
  - 政府分批注入国企股权
  - 部分资产剥离私有化
        ↓
【扩展阶段 1990-2008】
  - 90 年代起开始海外投资
  - 1992 起进入中国市场
  - 90 年代末入股渣打银行
        ↓
【转型阶段 2008-2014】
  - 2008 金融危机判断底部，逆势加仓
  - 大举买入美股、欧洲金融
  - 与 BK Capital 等合作进入 PE
        ↓
【中国加仓阶段 2014-2021】
  - 沪港通前后加大 H 股配置
  - 蚂蚁、菜鸟、京东物流中后期投资
  - 中国敞口峰值 27%（2020）
        ↓
【地缘再平衡 2021-2024】
  - 反垄断 + 共同富裕 → 减仓部分中概
  - 加仓印度（塔塔、信实、HDFC Bank）
  - 加仓北美科技
  - 中国敞口回落 16-18%
```

### 6.2 重大负面事件

```
【1】2020.11 蚂蚁 IPO 暂停
  - 账面巨额浮亏
  - 短期财报落后指数
  - 但不卖、不减仓（长钱纪律）
        ↓
【2】2021-2022 中概互联回撤
  - 中国敞口拖累整体回报
  - 主动减仓部分高 beta 标的
        ↓
【3】2022-2023 美国 BIOSECURE 类法案
  - 药明系列持仓大幅回撤
  - 触发"地缘风险 + 行业回撤" 双重打击
```

### 6.3 重大正面事件

```
【1】2014-2017 中国互联网牛市
  - 蚂蚁、阿里、菜鸟、京东持仓翻倍
  - 中国成为最大单一国别配置
        ↓
【2】长期持有 DBS（新加坡星展银行）
  - 当前是新加坡市值最大公司
  - 淡马锡持续 51% 持有
  - 投入资本回报率极高
        ↓
【3】2013-2014 中国段加仓节奏
  - 2018 熊市前 1-2 年逐步建仓
  - 风险调整回报被后续验证
```

### 7.2 五大核心区别

```
【资金属性差异】
  淡马锡 = 国有股权（从一开始就是主动持有的股权）
  GIC = 外汇储备分流（被动承接，需要平衡风险）
  CIC = 外汇储备分流（"外汇储备多元化"副产品）
  NBIM = 石油基金（被动承接油气收入，需维持购买力）
  ADIA = 石油基金（与 NBIM 类似的被动积累）
        ↓
【投资行为差异】
  淡马锡：派董事、推战略、单笔集中、长周期
  GIC：分散化、被动偏多、外包给外部资管
  CIC：政策导向、配置保密、规模最大但 alpha 难评估
  NBIM：被动为主 + ESG、规则透明、回报稳定
  ADIA：被动 + 内部 alpha、聚焦新兴市场
        ↓
【地缘敞口】
  淡马锡：中国峰值 27%，当前 16-18%
  GIC：美国 ~40% 为最大单一国别
  CIC：境内 + 美国对冲，海外分散
  NBIM：全球分散，美国 ~60% 权益
  ADIA：北美 + 亚洲双线
```

## 八、对个人 / 机构投资者的策略含义

### 8.1 核心借鉴清单

| 淡马锡风格 | 对应策略动作 |
|------------|--------------|
| 长周期持股 | 你的核心仓位也持有 5 年以上 |
| 集中持仓 10-20 只 | 不要零散买 100 只，找你的"前 10 持仓" |
| 积极股东 + 推战略 | 关注你持仓公司的董事会动向 |
| 行业分散但偏好长期复利行业 | 重仓金融、消费、医疗、科技 |
| 不加杠杆、不做空 | 永远不在主仓上做衍生品 |
| 公开持仓 + 接受监管 | 学习透明度，把你的仓位逻辑写清楚 |

### 8.2 淡马锡动作的"反向信号价值"

```
淡马锡的"减仓动作"是高 alpha 信号：

历史案例：
  - 2018-2019 减某些医药股 → 后续 1-2 年医药板块见顶
  - 2021-2022 减部分中概互联 → 后续 1-2 年板块 -60% 至 -80%
  - 2023 减某些印度 IT → 后续 AI 颠覆风险显现
        ↓
操作方法：
  1. 关注淡马锡年报新增 / 退出前 10 大持仓
  2. 关注 GIC、ADIA、NBIM 的同期动作（同向性高）
  3. 解读其"为何加 / 为何减"，比读券商研报更直接
```

### 8.3 局限与适用边界

```
淡马锡"可借鉴部分"：
  - 长周期持仓风格
  - 集中持仓 + 推战略
  - 公开仓位逻辑
        ↓
淡马锡"学不来部分"：
  - 主体资金量级（个人无法复制）
  - 董事会参与权（散户天然没有）
  - 国资背景带来的"非财务"影响力
        ↓
"学一半"：
  - 学其持仓理念 + 退出节奏
  - 不学其主体行动（不在你能力圈）
  - 把它当作"机构长钱的宏观信号"，不是"抄作业清单"
```

## 十、一句话总结

> **淡马锡 = 新加坡国有资产"主动管理"型主权财富基金**：1974 年成立，财政部全资持有，按"长周期 + 积极股东" 风格管理全球 USD 289 b 组合，是全球透明度最高的 SWF 之一。
>
> 它不同于 GIC（外汇储备分流）、不同于 CIC（中投，国有外汇储备分流）、不同于挪威 NBIM（石油基金），淡马锡是主权基金里最像"PE 控股公司" 的一家：单笔集中、长持、派董事、推战略。
>
> 中国资产历史上是淡马锡第二重要市场（峰值 27%），2024 年回落至 16-18%。这条曲线是机构长钱"对中国风险溢价"的最具参考价值的隐含基线。
>
> 它的持仓年报是公开的。学习它的"持仓逻辑 + 进退时点"，比任何券商研报都更接近"机构长钱" 的真实判断。
>
> **理解淡马锡 = 理解三件事**：
> 1. 主权财富基金的"积极股东" 模式：长钱、长心、长期
> 2. 新加坡国资治理：政府管股权、独立董事会管运营
> 3. 机构长钱对中国的 implicit 基准：6% 至 18% 至 27% 的三层仓位映射
